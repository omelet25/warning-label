A single self-contained Python program that writes one safety warning label for human beings — the one about volatile memory, which forgets your name in seconds yet keeps one embarrassing moment from 2009 in perfect, undeleteable detail — to /output/entry.txt. One line, 159 characters, standard library only, no network, byte-identical on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, one line, 159 characters).
